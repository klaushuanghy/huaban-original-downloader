# 常见问题

## 点击“读取并下载”没有反应

先看顶部连接状态。未连接时，确认运行过当前目录的安装脚本，且没有移动目录；移动后需要重新安装本地连接。关闭旧任务页，再从插件图标打开。初版连接持续打开时的消息缓冲问题已修复，当前版本带持续连接测试。

确认输入的是 `https://huaban.com/boards/画板ID`，不是单张采集链接。花瓣页面应正常登录并能看到目标画板。清单读取中显示错误时，按提示重试；不要反复快速点击。

## 能下载私密画板吗

只处理当前登录账号通过正常页面接口可访问的画板。不绕过权限，也不承诺所有私密或特殊类型画板均兼容。

## 原图是不是来源网站最大的图片

这里的原图指花瓣“查看大图”实际提供的版本。工具保持返回字节、真实尺寸和格式，不追溯来源网站，也不放大缩略图。

## 为什么有些文件名还是 UUID 或很短

文件名来自该条采集的花瓣标题/描述。如果采集本身使用 UUID、文件名或短描述，保存的名称也会对应它。采集 ID 始终保留用于定位，同名不会互相覆盖。

## 为什么图片数量和不同内容的数量不一样

不同采集可能指向相同图片。每条采集按各自 ID 保留；JSON 结果中另有不同内容数量。不会为了去重遗漏采集记录。

## 为什么等待很久或提示访问受限

网站可能限流。默认最多两个并发传输，整体请求间隔约 1.8 秒，遇限流自动退避。持续受限时停止并保留任务，稍后继续。图片链接过期则从插件更新清单。不要把提高并发当作解决访问限制的办法。

## 改名失败会重新下载吗

不会。已通过内容核验的文件保留原文件名，改名会短暂重试；持续失败则提示关闭占用程序后重新核验。文件缺失、内容损坏或原图键改变时才需要重新获取。

## 已下载图片能搬家吗

可以自行移动，但现有任务保存的路径不会自动跟着改变。请保留原路径，或作为新任务重新读取并核验。更改页面中的默认保存文件夹不迁移已有任务。

## 支持 macOS、Linux、手机吗

目前发行包只面向 Windows x64。源码中的 C# 启动器、注册表安装和系统 curl 调用需要适配后才能支持其他平台。Chrome 已做真实画板流程验证；Edge 未做专项验证。

## 能绕过验证码或下载失败的权限限制吗

不能。需要用户在花瓣正常完成登录或访问确认。工具不会自动解决验证码、关闭浏览器安全保护或改变企业策略。
