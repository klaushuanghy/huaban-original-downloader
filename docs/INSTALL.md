# 安装、更新和卸载

## 安装

1. 从本项目 [Releases](https://github.com/klaushuanghy/huaban-original-downloader/releases/latest) 下载 Windows x64 ZIP 和旁边的 `.sha256` 校验文件。
2. 完整解压。保留 `app`、`extension`、`runtime` 等目录的相对位置，不要在 ZIP 内直接运行。
3. 双击 `安装本地引擎.cmd`，看到成功提示后关闭提示窗口。此步骤不需要管理员权限。
4. Chrome 地址栏输入 `chrome://extensions`。Edge 对应 `edge://extensions`。
5. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压目录的 `extension` 文件夹。
6. 在扩展菜单中固定“花瓣原图下载器”，方便以后打开。
7. 登录花瓣，打开要下载的画板，点击插件图标。页面顶部显示“本地引擎已连接”后，确认画板链接，选择文件夹，点击“读取并下载”。

发布包带有运行环境。直接双击 `HuabanDownloader.exe` 只会显示说明，日常入口是浏览器插件。企业管理的浏览器可能禁止本地扩展，需由管理员处理；本项目不修改管理策略。

## 日常操作

- 暂停：当前传输结束后停止，记录进度。
- 继续下载：先核验已有文件，再补齐未完成项。
- 重新核验：逐张检查，并按当前标题规则更新文件名。
- 检查新增采集：重新读取整板清单，刷新签名地址，补齐新增或缺失项。
- 生成压缩包：全部核验完成后可用；压缩包与清单保存在画板目录。

下载开始后可关闭任务页或浏览器，本地工作进程会继续。读取清单阶段请保持浏览器打开，等到任务开始下载后再关闭。

## 更新

1. 先暂停正在运行的任务，保留旧目录作为备份。
2. 把新发行包解压到新目录。需要继承任务时，将旧目录的 `state` 文件夹复制到新目录，原下载图片保留在原位置。
3. 在新目录运行 `安装本地引擎.cmd`，更新当前用户的本地连接位置。
4. 在扩展管理页移除旧版扩展，再从新目录加载 `extension`。扩展 ID 固定，重载后会连接新引擎。
5. 打开任务页，确认保存位置和已有任务，再继续下载。

重载插件可能中断清单读取；已下载的原图保留。升级后建议先对一个小画板核验。

## 路径和文件

`state/` 位于安装目录，用于保存任务和设置；默认图片位置为安装目录的 `Downloads/`，也可在页面选择其他目录。更改默认保存位置仅影响新画板，已有画板继续使用原路径。移动已下载的画板目录不会自动更新已有任务路径。

移动安装目录后重新运行安装。不要把安装目录放在只读位置。完整标题查 `采集清单.csv`；无标题、非法字符、超长标题会按 README 的规则处理。

## 核对安装包

在 PowerShell 中运行 `Get-FileHash -Algorithm SHA256 .\HuabanOriginalDownloader-v1.1.0-windows-x64.zip`，与发布页 `.sha256` 文件中的值比较。

## 卸载

先在浏览器移除插件，再双击原安装目录的 `卸载本地连接.cmd`。它只移除当前用户的本地连接注册项，不删除图片和任务。确认不再需要后可自行删除安装目录。
