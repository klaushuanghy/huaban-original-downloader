花瓣原图下载器

Windows 10 / 11 · Chrome / Edge

第一次使用

  1. 将安装包完整解压到一个固定文件夹，不要在 ZIP 内直接运行。
  2. 双击“安装本地引擎.cmd”。只注册当前 Windows 用户的本地连接，不需要管理员权限。
  3. 打开 Chrome 的“扩展程序”管理页（chrome://extensions），开启“开发者模式”，点击“加载已解压的扩展程序”，选择安装目录中的 extension 文件夹。Edge 对应 edge://extensions。
  4. 在花瓣登录并打开画板，点击浏览器工具栏里的“花瓣原图下载器”图标。找不到时，可从扩展菜单中固定图标。

日常下载

粘贴花瓣画板链接，按需更改保存文件夹，点击“读取并下载”。插件会分页读取清单，核对画板数量，再让本地引擎保存原图。

标题文件名

图片以“花瓣标题_采集ID.实际格式”保存。同名采集保留各自 ID；标题过长时截短，非法字符替换为下划线，无标题使用“未命名采集”。完整标题可查 CSV 清单。已有旧文件点击“重新核验”后会自动改名，不重新下载。

暂停和恢复

点击任务中的“暂停”，当前传输完成后停止。点击“继续下载”可恢复；已保存的文件会先核验，合格文件不会重新下载。下载开始后关闭任务页或浏览器，本地任务仍会继续。

补齐新增采集

已完成任务点击“检查新增采集”。插件重新读取清单，更新临时原图地址；已有合格文件会跳过，只补新增或缺失项。移除的采集对应的已下载文件会保留。

遇到限流或链接过期

限流时会自动等待并恢复；持续受限时保留任务，稍后继续。链接过期时，回到花瓣确认正常登录，再点击“更新清单并继续”。本工具不会自动处理验证码或跳过访问限制。

完成与核验

“已完成”表示当前清单中的每条采集都有合格文件。打开文件夹可查看原图、采集清单.csv、校验清单.sha256 和下载核验结果.json。需要整包时点击“生成压缩包”。重复采集分别保留，可用清单查到每条详情链接。

位置与连接

原图保存在你选择的位置。下载器自己的任务记录保存在安装目录的 state 文件夹。移动安装目录后，重新运行安装即可更新本地连接；移动已下载文件后，需要重新选择位置或自行保留原任务路径。

插件仅申请花瓣网站访问、当前标签操作、本地存储和本地引擎连接权限。不会索取花瓣密码，不导出账户 Cookie，不将图片或任务上传到第三方服务。

卸载

先在浏览器移除插件，再双击“卸载本地连接.cmd”。已下载的原图和任务记录不会删除。确认不需要之后，可自行移除安装目录。

版本与原图范围

版本 1.1.0。原图指花瓣“查看大图”当前提供的文件；保持返回字节和实际格式，不放大或重新压缩。网站接口、图床域名或登录方式变化时，工具可能需要更新。下载规则位于 app/config.json；修改前请先暂停任务。
